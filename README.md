# apt

An APT repository for [Orchestrator](https://github.com/kbarendrecht/orchestrator),
served by GitHub Pages at <https://kbarendrecht.github.io/apt>.

```sh
curl -fsSL https://kbarendrecht.github.io/apt/orchestrator.asc \
  | sudo tee /usr/share/keyrings/orchestrator.asc > /dev/null
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/orchestrator.asc] https://kbarendrecht.github.io/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/orchestrator.list > /dev/null
sudo apt update && sudo apt install orchestrator
```

`apt upgrade` carries you to each new release after that. `apt remove
orchestrator` takes the app, the daemon and `orch` away again.

**amd64 only.** The app builds one Linux target, so there is no arm64 `.deb` to
publish. On an ARM machine, install through
[mise](https://github.com/kbarendrecht/orchestrator#through-mise-with-the-github-backend)
instead.

## What is here

| Path | What it is |
| --- | --- |
| `orchestrator.asc` | The public half of the signing key, and the file `signed-by` names |
| `pool/main/o/orchestrator/` | The `.deb` of each of the last few releases |
| `dists/stable/` | The index apt reads, and the signature over it |

Everything but `orchestrator.asc` is generated by
`.github/workflows/publish.yml`. Do not edit it by hand: the next run rewrites
it.

The private half lives in this repository's `APT_GPG_KEY` secret and nowhere
else. It signs this index and nothing else, so replacing it costs one run of the
workflow plus the keyring on each installed machine.
